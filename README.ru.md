# Zombie Apocalipse++

English documentation: [README.md](README.md).

**ZPP** — серверный мод на зомби-апокалипсис для **Minecraft Java 1.20.1 / Fabric / Java 17**.
Игроки могут подключаться обычным клиентом 1.20.1: установка ZPP и Fabric API на клиент не требуется.
Мод также работает на встроенном сервере одиночного мира, если установлен локально вместе с Fabric API.

Четыре настоящих ванильных типа: **зомби, утопленник, кадавр, зомби-житель**. Их поведение,
экипировка, лечение зомби-жителей и превращения остаются механиками Minecraft.

## Установка

1. Подготовьте сервер Minecraft **1.20.1** с Fabric Loader **0.15.11+** и Java **17+**.
2. Положите `zombie-apocalipse-plus-plus-1.0.0+1.20.1.jar` и **Fabric API для 1.20.1** в `mods/` сервера.
   Разработка и проверка выполнены с Loader 0.15.11 и Fabric API 0.92.2+1.20.1.
3. Запустите сервер. Файл настроек появится в папке мира: `world/zpp.json` на выделенном сервере или `saves/<имя мира>/zpp.json` в одиночной игре.
4. Выполните `/zpp`, затем `/zpp help`. Мод по умолчанию выключен; включите его командой `/zpp toggle` или `/zpp enabled true`. Менять настройки могут операторы с уровнем **2**.

Готовый мод после сборки: `build/libs/zombie-apocalipse-plus-plus-1.0.0+1.20.1.jar`.
JAR с суффиксом `-sources` содержит исходники и не предназначен для папки `mods/`.

## Быстрый старт

```mcfunction
/zpp dayburn False
/zpp dayspawn amount 3
/zpp babies false
/zpp variants zombie 65
/zpp variants drowned 10
/zpp variants husk 15
/zpp variants zombie_villager 10
/zpp enabled true
/zpp status
```

- `dayburn false` отключает солнечное горение у поддерживаемых зомби. `true` возвращает
  ванильное поведение: кадавры по-прежнему не горят на солнце. Уже полученный огонь догорает обычно.
- **По умолчанию `dayspawn amount = 0`: дополнительных дневных волн нет.**
  `/zpp dayspawn amount 3` задаёт попытку создать 3 зомби на игрока за волну после включения ZPP.
  `/zpp dayspawn amount 0` снова выключает дневные волны. Сокращение: `/zpp dayspawn 3`.
- `True`, `False`, `true`, `false` допустимы. Указывать квадратные скобки не нужно.
- `babies false` запрещает детёнышей всех четырёх типов, включая естественный спавн;
  уже загруженные детёныши становятся взрослыми. Зомбифицированные пиглины не затрагиваются.
- Вес `0` исключает тип из **волн ZPP**. Веса относительные, их сумма может отличаться от 100.
  Ванильный биомный спавн и превращения мобов не регулируются этими весами.

## Что включено

- Дополнительные волны вокруг игроков в выживании/приключении в **обычном мире**.
- Независимые количества дневных и ночных волн, интервал, дистанция, лимиты, свет и открытое небо.
- Четыре типа зомби по умолчанию и дополнительные мобы по их ID; утопленники могут появляться на суше и у поверхности воды.
- Орды каждую седьмую ночь и случайные кровавые луны с полноэкранными объявлениями.
- Усиление здоровья, урона и скорости по игровым дням с верхней границей.
- Пауза после смерти игрока, льготные первые дни и безопасные грибные поля.
- Постоянная статистика убийств и сообщений о рубежах 100 / 500 / 1000 / каждые 5000 убийств.
- Пресеты, автодополнение команд, просмотр настроек и перечитывание JSON без перезапуска.

Кровавая луна — событие с усиленными волнами и полноэкранным сообщением. Все объявления ZPP, включая новый день,
показываются ванильным экранным заголовком. При новом дне выводится только номер дня, без процента усиления зомби.
Текстура луны остаётся ванильной.
Орды и кровавые луны умножают число мобов в волне, а не их характеристики. Нулевое количество
остаётся нулём при любых событиях. Максимум — 64 попытки спавна мобов в одной волне.

## Начальный баланс

Сам мод **выключен по умолчанию**. Значения ниже действуют после включения переключателя.

| Параметр | Значение |
|---|---|
| Главный переключатель | выключен (`enabled=false`) |
| Солнечное горение | выключено |
| Дневная волна | **0**, выключена |
| Ночная волна | 2 зомби каждые 15 секунд на игрока |
| Льготные дни | 0; волны доступны сразу после включения |
| Ночь для ZPP | время суток 13000–22999 |
| Дистанция появления | 24–48 блоков |
| Лимит вокруг игрока | 32 живых моба из списка волн |
| Общий лимит | 256 загруженных мобов, созданных ZPP |
| Защита светом | спавн при свете от блоков ≤ 7; солнечный свет не считается |
| Открытое небо | требуется |
| Детёныши | выключены; шанс при включении — 5% |
| Веса типов | зомби 65, утопленник 10, кадавр 15, зомби-житель 10 |
| Орда | каждая 7-я ночь, 120 секунд, ×3 |
| Кровавая луна | 15% на ночь, ×2 до рассвета |
| Защита после смерти | 60 секунд от автоматических волн |
| Полное усиление | с 31-го дня: +150% здоровья, +75% урона, +20% скорости |

`/zpp spawn grace 0` отключает льготный период. По умолчанию льготных дней нет. При обычных настройках факелы действительно
защищают базу от дополнительных волн, поэтому удачных появлений может быть меньше заказанного числа.

## Команды

Значение настройки без аргумента можно прочитать без OP. Изменения, ручные события,
ручной спавн, `config` и `reload` требуют OP 2. В консоли сервера начальный `/` не нужен.

| Команда | Назначение / диапазон |
|---|---|
| `/zpp`, `/zpp status`, `/zpp help` | сводка и помощь |
| `/zpp enabled <true\|false>` | главный переключатель механик ZPP |
| `/zpp toggle` | переключить мод между включённым и выключенным состоянием |
| `/zpp dayburn <true\|false>` | ванильное горение от солнца |
| `/zpp dayspawn [amount] <0..64>` | дневное число попыток спавна |
| `/zpp nightspawn [amount] <0..64>` | ночное число попыток спавна |
| `/zpp babies <true\|false>` | разрешить детёнышей |
| `/zpp babies chance <0..100>` | процент детёнышей в волнах ZPP |
| `/zpp variants` | текущие веса |
| `/zpp variants list` | список всех мобов в волнах и их весов |
| `/zpp variants <тип> <0..1000>` | вес `zombie`, `drowned`, `husk`, `zombie_villager`; хотя бы один вес > 0 |
| `/zpp variants add <id> <0..1000>` | добавить моба по ID, например `minecraft:skeleton` или `example:infected` |
| `/zpp variants remove <id>` | удалить моба из волн; последний вариант удалить нельзя |
| `/zpp spawn <тип> <1..64> [игрок]` | ручная волна вокруг себя или указанного игрока |
| `/zpp spawn interval <2..3600>` | интервал на игрока, секунды |
| `/zpp spawn cap <1..256>` | локальный лимит мобов из волн |
| `/zpp spawn globalcap <1..4096>` | общий лимит загруженных мобов ZPP |
| `/zpp spawn distance <8..96> <9..112>` | минимальная и максимальная дистанция; min < max |
| `/zpp spawn attempts <1..32>` | число поисков позиции на одного моба |
| `/zpp spawn maxlight <0..15>` | максимальный свет от блоков |
| `/zpp spawn opensky <true\|false>` | требовать небо; при false ищет поверхности около высоты игрока |
| `/zpp spawn grace <0..365>` | число начальных игровых дней без автоматических волн |
| `/zpp spawn cooldown <0..3600>` | пауза волн после смерти, секунды |
| `/zpp scaling <true\|false>` | усиление по дням |
| `/zpp scaling days <1..3650>` | число дней до максимальных бонусов |
| `/zpp scaling health <0..10>` | максимальный дополнительный множитель базового здоровья |
| `/zpp scaling damage <0..5>` | максимальный дополнительный множитель базового урона |
| `/zpp scaling speed <0..1>` | максимальный дополнительный множитель базовой скорости |
| `/zpp scaling natural <true\|false>` | применять усиление также к естественным мобам из списка |
| `/zpp horde` | состояние орды |
| `/zpp horde enabled <true\|false>` | включить систему орд |
| `/zpp horde start [10..3600]`, `/zpp horde stop` | начать орду на указанное число секунд / остановить |
| `/zpp horde every <1..365>` | период в игровых днях; начало ночью |
| `/zpp horde duration <10..3600>` | длительность автоматической орды, секунды |
| `/zpp horde multiplier <1..8>` | множитель волн во время орды |
| `/zpp bloodmoon` | состояние кровавой луны |
| `/zpp bloodmoon enabled <true\|false>` | включить систему кровавых лун |
| `/zpp bloodmoon start`, `/zpp bloodmoon stop` | начать ночью / остановить |
| `/zpp bloodmoon chance <0..100>` | вероятность на каждую ночь |
| `/zpp bloodmoon multiplier <1..8>` | множитель волн |
| `/zpp announcements <true\|false>` | полноэкранные объявления дней и событий |
| `/zpp day` | день мира, начиная с 1 |
| `/zpp stats [игрок]` | статистика сервера / игрока онлайн |
| `/zpp preset <casual\|standard\|hardcore>` | настроить интенсивность |
| `/zpp preset list` | показать встроенные и сохранённые пресеты |
| `/zpp preset save <имя>` | сохранить все текущие настройки как общий пресет для всех миров установки |
| `/zpp preset load <имя>` | применить сохранённый пресет к текущему миру |
| `/zpp preset delete <имя>` | удалить сохранённый пресет |
| `/zpp config`, `/zpp reload` | путь к JSON / перечитать его |

Ручной спавн пропускает льготный период, паузу после смерти и дневное/ночное количество.
Он сохраняет проверки места, общего переключателя, сложности, gamerule и лимитов.
Консоль должна указать игрока, например `zpp spawn zombie_villager 4 Steve`.

Пресеты оставляют дневной спавн выключенным. Casual: 1 моб / 25 сек., лимит 16, 3 льготных дня,
без орд и кровавых лун. Standard: начальный баланс. Hardcore: 4 / 8 сек., лимит 48,
детёныши разрешены, свет до 15, полное усиление через 15 дней. Пресеты сохраняют веса типов,
общий лимит, защиту после смерти и выбор объявлений; это не полный сброс JSON.
Пресеты не включают мод. При изменении настроек, пока ZPP выключен, команда сообщает, что они начнут действовать после включения.

Сохранённые пресеты лежат в `config/zpp-presets.json` каталога Fabric и доступны во всех мирах той же установки.
Имя: 1–32 строчные латинские буквы, цифры, `_` или `-`; имена встроенных пресетов зарезервированы.
`save` сохраняет полный снимок настроек, включая `enabled` и список мобов. `load` переносит эти значения в
`zpp.json` текущего мира. Для ID мобов из других модов соответствующий мод должен быть установлен при применении
пресета. Встроенные пресеты по-прежнему меняют только перечисленные выше параметры.

`variants add` принимает ID зарегистрированного моба. Короткие имена четырёх исходных зомби сохраняются;
их полные ID (`minecraft:zombie` и т. п.) тоже принимаются. Вес `0` оставляет моба в списке, но исключает
из случайных волн. `remove` удаляет запись целиком. Детёныши настраиваются только для зомби;
усиление характеристик действует и на добавленных мобов, если у них есть соответствующие атрибуты.
Водные мобы появляются у поверхности воды. Добавленные мобы участвуют в лимитах и статистике убийств.

## Работа сервера и сохранения

Спавн ZPP соблюдает `doMobSpawning`, мирную сложность, границу мира, коллизии,
минимальную дистанцию до игроков и загруженность чанков. Грибные поля защищены.
Выгруженные чанки для поиска позиции не загружаются и не генерируются. За тик обрабатывается
не более одной волны одного игрока; при большом онлайне реальный интервал может увеличиться.
Мобы не делаются постоянными, поэтому работают ванильные правила деспавна.

Локальный лимит учитывает мобов из списка волн в области вокруг игрока, включая естественных,
а также ранее созданных ZPP мобов, даже если их тип уже удалён из списка.
Общий лимит учитывает только **загруженных** мобов с меткой `zpp.spawned` и ограничивает новый
спавн. Загрузка старых чанков и снижение лимита не удаляют уже существующих мобов.

Волны и события работают в Overworld. Запрет детёнышей, солнечное горение и усиление
поддерживаемых типов применяются во всех измерениях; день усиления берётся из Overworld.
Мод не заменяет естественную систему появления других монстров.

Настройки каждого мира хранятся в его папке в `zpp.json`. Общий `.minecraft/config/zpp.json` больше не используется;
если нужны прежние значения, перенесите их вручную в папку нужного мира.
Настройки записываются при каждой команде через временный файл и замену. Неверная настройка
не применяется. Ошибочный `/zpp reload` оставляет работающую конфигурацию в памяти;
некорректный JSON при запуске останавливает сервер с указанием файла, не затирая его.
После исправления повторите reload или запуск.

Статистика и состояние событий хранятся в `world/data/zpp.dat`, отдельно для каждого мира.
События и их таймеры сохраняются при перезапуске; время отсчитывается в тиках сервера.
Пауза после смерти хранится в памяти до перезапуска. Сон и `/time` влияют на дни и события.
Усиление обновляется на новом дне, при загрузке моба и изменении настроек, без накопления
повторных модификаторов. Отношение текущего здоровья к максимальному сохраняется.

Перед удалением мода выполните `/zpp enabled false`: бонусы снимаются с загруженных мобов,
а с остальных — при их последующей загрузке, пока мод ещё установлен. Если сразу удалить
JAR, сохранённые в выгруженных чанках модификаторы атрибутов могут остаться.

## Сборка и проверка

```sh
# Gradle 8.12 запускайте именно под JDK 21.
./gradlew build
./gradlew runIntegrationTest
```

На Windows: `gradlew.bat build`. Если `JAVA_HOME` указывает на JDK 25, переключите его на 21
перед сборкой. Wrapper сам скачает Gradle и проверит SHA-256 дистрибутива.

`build` выполняет тесты конфигурации и расчётов. `runIntegrationTest` поднимает изолированный
Fabric-сервер на localhost с временным миром, выполняет проверки команд, миксинов,
событий и реального спавна всех типов, затем останавливает сервер. Задача пересоздаёт
только `build/integration-server/`; тестовый мод не входит в релизный JAR.

Технические детали и ограничения проверки: [docs/TESTING.md](docs/TESTING.md).
