# Проверка ZPP 1.0.0+1.20.1

Целевая среда: Minecraft 1.20.1, Fabric Loader 0.15.11+, Fabric API 0.92.2+1.20.1,
Java 17+. Сборка и интеграционный сервер проверены с OpenJDK 21 / Gradle 8.12; JAR скомпилирован с `--release 17`.

## Автоматические проверки

`./gradlew build` запускает 8 JUnit-тестов:

- выключенный дневной спавн и состав четырёх типов;
- чтение/запись JSON и значения отсутствующих полей;
- сохранение прежнего состояния при ошибке команды или reload;
- валидация весов, дистанций и ограничений чисел;
- границы игровых дней и ночи;
- нулевые количества при пересечении событий и бюджет волны;
- ограниченная прогрессия сложности.

`./gradlew runIntegrationTest` запускает отдельный Fabric-сервер и выполняет проверки:

- регистрация дерева `/zpp`, варианты синтаксиса и регистр boolean;
- запрет изменений для источника с уровнем прав 0, доступность сводки;
- отбрасывание неверных диапазонов без изменения настроек;
- отсутствие выбора типа с весом 0;
- ручные орды и кровавые луны, запрет запуска луны днём;
- автоматическая орда на седьмую ночь, отсутствие дневного запуска;
- применение миксинов горения и запрета детёнышей;
- сохранение поведения зомбифицированных пиглинов;
- усиление без накопления бонусов и сохранение доли здоровья при отключении;
- реальный спавн всех четырёх типов на загруженной площадке;
- дистанция, локальный и глобальный лимиты;
- сохранение усиления после NBT-перезагрузки;
- шанс детёнышей 100%, запрет лишних куриц-наездников и перевод загруженных детёнышей во взрослых;
- утопленники у поверхности воды с требованием открытого неба;
- `doMobSpawning`, главный переключатель и сериализация статистики.

Тестовый сервер завершает работу сам. Gradle проверяет наличие `PASSED.txt`; ошибка проверки
делает задачу неуспешной. Мир и настройки в `build/integration-server` пересоздаются перед запуском.
Задача использует тестового ServerPlayerEntity, без сетевого подключения клиента.

## Проверка выпуска

Готовый remapped JAR дополнительно запускался на обычном выделенном Fabric-сервере
с Fabric API, без тестового мода и без среды разработки. Проверены загрузка,
`zpp status`, `zpp dayburn False`, `zpp dayspawn amount 2`, создание зомби через
`summon`, отключение дневного спавна, сохранение и штатная остановка. Ошибок загрузки
классов или миксинов не обнаружено. Лог этой проверки: `build/smoke-server/smoke.log`.

## Границы проверки

Не проводились длительная игровая сессия с настоящими клиентами, нагрузочный тест
на большом онлайне или проверка совместимости со сторонними модпаками. Для баланса
конкретного сервера стоит начать с `standard`, наблюдать TPS и при необходимости снижать
`cap` / `globalcap` / количество мобов или увеличивать интервал.
